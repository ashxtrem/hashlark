Open device sizes, rotation, and zoom checks ↗

750 × 780 layout pixels: a 420 dpi inner-screen model with an illustrative 52 dp system-UI allowance. The earlier 840 px frame was a generic breakpoint preview, not a verified Fold7 size. At this width, tap a result to open full-screen details; the current mock does not show both panes at once.
